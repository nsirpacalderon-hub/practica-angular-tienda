# Práctica: Presentación de un producto en Angular

Proyecto realizado para la práctica de Angular.

## Contenido
- Datos de la tienda en `src/app/app.ts`
- Interfaz `Producto`
- Presentación en `src/app/app.html`
- Estilos en `src/app/app.css`
- Uso de `@if`, `@for` e interpolación `{{ }}`

## Ejecutar
1. Instalar Node.js.
2. Abrir una terminal dentro de esta carpeta.
3. Ejecutar:

```bash
npm install
npm start
```

4. Abrir `http://localhost:4200`.
